# AQI Smart Assistant

An AI-powered Air Quality Prediction and Smart Chatbot System built using Machine Learning to forecast Air Quality Index (AQI) and provide intelligent environmental insights.

---

## Overview

AQI Smart Assistant is a Machine Learning-based application that predicts Air Quality Index (AQI) using historical environmental data. The project also includes an intelligent chatbot that helps users understand air quality, pollution levels, and health recommendations.

The objective of this project is to provide an efficient system for predicting air quality and assisting users in making informed environmental decisions.

---

## Features

- Air Quality Index (AQI) Prediction
- Machine Learning-based Forecasting
- Intelligent Chatbot
- Data Analysis using Historical AQI Dataset
- Fast Prediction using Trained Models
- CSV Dataset Support

## Installation

Clone the repository:

```bash
git clone https://github.com/shavi-gongale/AQI-Smart-Assistant.git
```

Navigate to the project directory:

```bash
cd AQI-Smart-Assistant
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
